Library paths

Source Manager writes .strm files directly into the library folders Jellyfin already scans. Leave blank to auto-discover from Jellyfin virtual folders; set only if auto-discovery picks the wrong folder.

Root folder of your Jellyfin Movies library, e.g. /media/movies
Root folder of your Jellyfin TV Shows library, e.g. /media/shows

Files are written as Movies/{Title}/{Title}.strm and Shows/{Title}/Season NN/{Title} - SNNENN.strm.

Auto source resolution

Khi Jellyseerr approve một request, Source Manager tự tìm stream theo thứ tự: KKPhim → OPhim (m3u8 → .strm) → YTS (torrent → qBittorrent).

Leave blank to disable torrent fallback. e.g. http://localhost:8080

Jellyseerr integration

Thêm Source Manager như một Radarr (phim) và Sonarr (series) instance trong Jellyseerr. Khi admin approve, Jellyseerr gửi thẳng vào Source Manager thay vì Radarr/Sonarr thật.

Cách cài trong Jellyseerr

1
Settings → Services → Radarr → Add Radarr Server → dán Radarr URL và API key ở trên
2
Quality Profile → Source Manager · Root Folder → thư mục movies
3
Settings → Services → Sonarr → Add Sonarr Server → dán Sonarr URL và API key ở trên
4
Quality Profile → Source Manager · Language Profile → Any · Root Folder → thư mục shows
5
Test Connection → Save (cả hai)
