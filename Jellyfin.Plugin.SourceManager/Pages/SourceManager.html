STRM library
When an admin approves a request with a stream URL, the plugin writes a .strm file here. Jellyfin scans it automatically and adds the item to the library.
Absolute path on the Jellyfin server. Leave blank to disable .strm writing.
Add these sub-paths as Jellyfin libraries:
/data/strm/movies → Movies
/data/strm/shows → TV Shows
Jellyseerr Integration
